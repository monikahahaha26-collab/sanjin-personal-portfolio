像素风（Pixel Art）很容易被误解为"必须依赖美术素材"。实际上，用纯 CSS 也能做出相当有辨识度的点阵视觉 —— 本站在首页的 **SANJIN 像素标识** 就是完全用代码生成的。

## 点阵字：把字母翻译成 5×7 网格

思路很简单：把每个字母定义成一个 `5×7` 的二维数组，`1` 代表实心、`0` 代表空心，再用 CSS Grid 逐格渲染。

```text
S: 01110
   10001
   10000
   01110
   00001
   10001
   01110
```

关键点是**每格用独立的小方块**而非一整块文字，这样每个格子都可以单独做弹出动画、单独上色。本站把魔方六色依次分给 S A N J I N 六个字母，正好呼应"彩绘魔方"的主题。

## 动画节奏：逐格弹出

给每个格子设置递增的 `animation-delay`（行内偏移 + 列偏移），就能形成"从左到右、从上到下"的扫描式浮现效果，比整体淡入更有"像素落位"的感觉。

```css
.pixel-cell {
  opacity: 0;
  animation: pixelPop 0.5s var(--ease-out) forwards;
}
.pixel-cell.on {
  animation-delay: calc(var(--row) * 45ms + var(--col) * 25ms);
}
```

## 等距魔方：两个 matrix 变换打天下

魔方装饰同样不用图片：一个 `3×3` 的面，用两组 `matrix` 变换就能投影成等距三面视图（顶面 / 左面 / 右面），再叠加不同透明度的黑色遮罩制造光照层次。

- 顶面：`matrix(0.866, 0.5, -0.866, 0.5, 0, 0)`
- 左面：`matrix(0.866, 0.5, 0, 1, 0, 0)`
- 右面：`matrix(0.866, -0.5, 0, 1, 0, 0)`

这样每个"魔方"都是一段几十行的 SVG 组件，可随意改配色、改尺寸、做动画 —— 比维护一张张图片要灵活得多。

## 小结

> 复古不等于过时，像素风的关键在于**统一性与节奏感**：统一的网格、克制的配色、有规律的动画延迟。

纯代码方案的优势很明显：零图片体积、任意换色、天然响应式。如果你也想做点阵视觉，不妨从这套「点阵字 + 等距魔方」的组合开始。
