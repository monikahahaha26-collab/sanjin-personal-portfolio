## 项目说明

该项目为 Java Web 课程设计，保留原始源码而未做技术栈改造。系统通过 Servlet 接收请求，Service 协调业务，DAO 使用 JDBC 访问 MySQL；前端使用 Bootstrap 和 jQuery 完成基础表单与列表展示。

## 可验证功能

- 管理员：图书信息、读者信息、借还记录、密码修改
- 读者：图书查询、借阅操作、个人信息、借阅历史
- 数据层：图书、读者、借阅记录等实体及对应 DAO

## 说明

该项目的价值在于 Java Web 基础分层、CRUD 和部署流程学习。由于运行需要匹配的本地数据库账号，网站仅展示源码自带页面的本地运行截图，不提供在线账号或源码下载。
