## 项目说明

AegisGift 将企业节日礼赠从“选品—询价—采购—审批—履约”串成一条可追踪流程。企业用户侧负责提交采购需求和查看订单，运营侧维护商品与供应链数据，审批人按企业阈值处理采购单，库存服务在下单、取消和完成之间维护可用量。

## 技术架构

```text
Vue 3 + Vite + Element Plus + lucide-vue-next（运营后台）
                         │ REST / JSON
Spring Boot 3.5 + Java 21（aegisgift-server）
  ├─ Controller / Service / Mapper（MyBatis）
  ├─ JWT：管理员与企业账号双鉴权
  ├─ Redis：缓存、库存状态与短期协调
  ├─ MySQL：礼品、供应商、企业、订单、库存流水
  ├─ Spring AI：可选的推荐叙述增强
  └─ pgvector：采购知识文档向量检索（RAG）
```
