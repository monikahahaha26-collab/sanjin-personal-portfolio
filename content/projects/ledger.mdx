## 项目概述

Mobile Ledger 是一款轻量级个人记账工具。核心场景是"随手记一笔"——走在路上、吃饭时掏出手机快速记一笔开支。电脑端则提供更完整的统计视图和数据管理能力。

## 技术架构

```
┌──────────────────────┐
│   前端 (www/)        │
│  PWA + Service Worker│
│  移动优先响应式 UI    │
└──────────┬───────────┘
           │ REST API
┌──────────▼───────────┐
│   Node.js 后端         │
│  Express + JSON 存储   │
│  /api/records 等接口   │
└──────┬───────────────┘
       │ 可选: 同步
┌──────▼───────────────┐
│  Android (Capacitor)  │
│  ledger.apk 原生包     │
└──────────────────────┘
```

## 核心功能

### 记账入口

- **手动输入**：金额 + 分类 + 备注，一键提交
- **语音输入**："花了三十块买午饭" → 自动解析金额和分类
- **快捷操作**：常用分类一键记（无需输入金额）

### 数据面板

- 总收入 / 总支出 / 结余概览卡
- 按分类的支出去向统计
- 明细查询（支持日期筛选）
- 同步状态指示器
