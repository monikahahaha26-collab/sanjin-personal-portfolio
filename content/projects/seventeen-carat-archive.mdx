## 项目概述

SEVENTEEN CARAT ARCHIVE 是一个粉丝向的 K-pop 团体成员档案与个人图库管理系统。核心设计理念是**隐私优先**——所有上传内容仅存储在用户自己的浏览器中，其他人访问同一网站看不到你的数据。

## 技术架构

```
┌──────────────────────────────────────┐
│        React + Vite SPA              │
│  ┌──────────┐ ┌───────────────────┐ │
│  │ 成员档案   │ │ 图库 (IndexedDB)  │ │
│  └──────────┘ └───────────────────┘ │
│  ┌─────────────────────────────────┐ │
│  │ 备份/恢复 (JSON 导入导出)       │ │
│  └─────────────────────────────────┘ │
└──────────────────────────────────────┘
       ↓ 静态部署 (无需服务端)
 Cloudflare Pages / Vercel / GitHub Pages
```

## 核心功能

### 成员档案系统

- 13 位成员独立页面，包含基本信息、代表色标签
- 首页支持设置"主推成员"，自定义入口展示
- 成员头像与封面图支持本地上传

### 本地图库

- 拖拽或点击上传图片/视频文件
- 自动生成缩略图（Canvas 压缩），原图存 IndexedDB
- 支持按成员筛选、时间排序
- 图片点击全屏预览，键盘左右切换

### 数据安全

- 所有数据通过 IndexedDB 存储在浏览器沙箱中
- 网站本身不收集任何用户数据
- 提供 JSON 格式的一键备份/恢复
