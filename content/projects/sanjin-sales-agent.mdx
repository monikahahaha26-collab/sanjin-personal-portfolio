## 项目说明

叁金销售数据分析 Agent 把“问数据”变成销售团队熟悉的对话入口。用户可以直接询问“本季度哪个大区增长最快？”或“最近有没有销售异常？”，Agent 根据意图选择专用工具，再将结果组织成可读结论和图表。

## 技术架构

```text
Vue 3 + Vite + Vue Router + Pinia + Element Plus
  ├─ Axios：登录、普通对话和会话清理
  ├─ fetch + SSE：消费 /agent/chat/stream 的增量 token
  └─ ECharts / vue-echarts：趋势、排名等图表
                         │ REST / SSE
Spring Boot 3.5 + Java 21
  ├─ LangChain4j：SalesAgent、@Tool 工具编排
  ├─ Spring Web / WebFlux：同步与流式接口
  ├─ Spring Data JPA：订单、产品、区域、销售员实体
  ├─ MySQL：业务数据与对话记忆
  ├─ Redis：销售查询缓存
  └─ Sa-Token + Validation + Actuator：权限、参数校验与健康检查
```
