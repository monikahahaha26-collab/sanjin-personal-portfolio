## 项目概述

这是一个面向公共事件舆情研究的毕业设计。系统围绕评论文本完成情感倾向判定、主题提取与可视化展示，用于观察公众对热点事件的情绪变化与关注主题。

## 系统架构

```
┌─────────────────────────────────────┐
│          Flask Web 应用              │
│  ┌──────┐ ┌──────┐ ┌──────────┐   │
│  │爬虫模块│ │NLP引擎│ │ 可视化层  │   │
│  │spider│ │analysis│ │ ECharts  │   │
│  └──┬───┘ └──┬───┘ └──────────┘   │
│     │         │                      │
│  ┌──▼─────────▼──────────────────┐  │
│  │       MySQL 数据库             │  │
│  │  (原始文本 / 情感标签 / 主题)   │  │
│  └───────────────────────────────┘  │
└─────────────────────────────────────┘
```

## 核心模块

### 数据采集 (spider/)

- 定向抓取微博超话/话题下的文章与评论
- 数据清洗：去重、去广告、HTML 标签剥离
- 结构化存储至 MySQL

### 情感分析 (model/)

- **规则方法**：基于情感词典（大连理工情感词汇库扩展）打分
- **模型方法**：BERT 微调分类器（正/负/中性三分类）
- 双重结果对比，可配置权重融合

### 主题分析 (wordcloud/)

- LDA 主题模型提取潜在话题分布
- TF-IDF 热词排名
- 词云生成（自定义形状蒙版）
