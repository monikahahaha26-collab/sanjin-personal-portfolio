## 项目概述

《余烬尖塔》是一款受《杀戮尖塔》（Slay the Spire）启发的浏览器 Roguelike 卡牌游戏。玩家选择角色、构建牌组、逐层攀登尖塔，在随机生成的战斗中做出战术决策。

## 技术架构

```
┌─────────────────────────────────┐
│     Vite + TypeScript 前端      │
│   (Canvas 渲染 / 状态管理)     │
└──────────┬──────────────────────┘
           │ REST API (fetch)
┌──────────▼──────────────────────┐
│   Cloudflare Worker (API)       │
│   ┌─────────────────────────┐   │
│   │ D1 数据库 (存档)        │   │
│   └─────────────────────────┘   │
└─────────────────────────────────┘
```

## 核心实现

### 卡牌引擎

- **牌组构建**：每角色初始 10 张基础牌，通过战斗奖励和商店购买扩展
- **战斗系统**：每回合抽手牌 → 消耗能量打出 → 敌人行动 → 结算效果
- **姿态切换**：攻击姿态（伤害+20%，受伤+10%）/ 防御姿态（格挡+30%，伤害-15%）

### 存档方案

优先使用 `localStorage` 存储进度（零延迟），用户登录后可选同步至 Cloudflare D1。Worker API 提供存档的 CRUD 与冲突合并。

## 部署

前端通过 `vite build` 构建为静态资源部署到 Cloudflare Pages；Worker + D1 通过 `wrangler deploy` 一键发布。
